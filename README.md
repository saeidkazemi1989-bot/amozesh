# قَدَم — انگلیسی، کم‌کم

اپ آموزش انگلیسی برای فارسی‌زبانانِ کاملاً مبتدی، با تمرین‌های کوتاه و بدون فشار. رابط راست‌به‌چپ و واکنش‌گراست و روی موبایل و دسکتاپ کار می‌کند.

## امکانات

- ۶۰ درس و ۱۸۰ عبارت کاربردی در ۱۰ سطح: سلام و احوال‌پرسی، معرفی، خانواده، غذا، آب‌وهوا، سفر، رستوران، خرید، آدرس، تکنولوژی و گفت‌وگوی روزمره
- هدف پیش‌فرض ۵ دقیقه در روز، قابل تغییر به ۳ یا ۱۰ دقیقه؛ زمان‌ها تقریبی هستند و شمارش معکوس ندارند
- معنی فارسی، راهنمای تقریبی تلفظ و پخش انگلیسی با صدای مرورگر
- تمرین انتخاب معنی، شنیدن و جمله‌سازی با کلمه‌ها
- حالت «فقط ۱ سؤال» برای روزهای کم‌حوصلگی
- پاسخ اشتباه بدون کسر امتیاز، همراه با نمایش جواب و توضیح
- ذخیرهٔ تمرین نیمه‌تمام و ادامه پس از بازکردن دوبارهٔ صفحه
- مرور فاصله‌دار با فاصله‌های ۱، ۳، ۷، ۱۴ و ۳۰ روز؛ پاسخ دشوار زودتر به مرور برمی‌گردد
- تاریخچه، روزهای تمرین و نشان‌های پیشرفت، بدون زنجیرهٔ روزهای متوالی یا تنبیه برای وقفه
- فایل پشتیبان JSON، بازگردانی تأییدشده و پاک‌کردن پیشرفت با تأیید صریح
- نسخهٔ ساخت‌شده پس از بارگذاری موفق اولیه، بدون اینترنت هم باز می‌شود
- قابلیت افزودن به صفحهٔ اصلی مرورگرهای پشتیبانی‌کننده، بدون نیاز به حساب کاربری
- دکمهٔ «بررسی به‌روزرسانی» داخل برنامه؛ به‌روزرسانی بدون پاک‌شدن پیشرفت و با استفادهٔ دوباره از فایل‌های تغییرنکرده

## اجرا

نیازمندی: Node.js 22 یا جدیدتر.

```bash
npm ci
npm run dev
```

سرور توسعه روی `http://localhost:5173` و رابط `0.0.0.0` اجرا می‌شود.

## ساخت و پیش‌نمایش

```bash
npm run build
npm run preview
```

خروجی در `dist/` ساخته می‌شود. برای انتشار، همین پوشه را روی یک میزبان وب استاتیک با HTTPS قرار دهید. سرویس‌ورکر فقط در نسخهٔ ساخت‌شده فعال است؛ کش آفلاین در سرور توسعه فعال نمی‌شود.

## آزمون‌ها

```bash
npm test             # آزمون منطق یادگیری، مرور، تاریخ و اعتبارسنجی داده
npm run test:e2e     # آزمون مرورگر، مسیر کامل تمرین، موبایل، تنظیمات و دسترس‌پذیری
npm run test:production # آزمون آفلاین؛ ابتدا build و preview را در پورت ۴۱۷۳ اجرا کنید
```

آزمون مرورگر از Chromium بسته‌بندی‌شده در وابستگی‌های توسعه استفاده می‌کند و روی Linux به نصب جداگانهٔ مرورگر نیاز ندارد. برای محیط دارای مرورگر استاندارد می‌توان تنظیمات `playwright.config.ts` را تغییر داد.

## نصب موبایل و به‌روزرسانی

برنامه یک PWA است، نه فایل APK. نشانی میزبانی‌شده را در Chrome اندروید یا Safari آیفون باز کنید و از «نصب برنامه / افزودن به صفحهٔ اصلی» استفاده کنید. مسیر `#install` راهنمای نصب را باز می‌کند.

دکمهٔ چرخش در نوار بالا، بخش به‌روزرسانی را باز می‌کند. «بررسی به‌روزرسانی» نسخهٔ میزبانی‌شده را بررسی می‌کند؛ اگر نسخهٔ تازه آماده باشد، با «به‌روزرسانی و بازکردن برنامه» اعمال می‌شود. پیشرفت در `localStorage` می‌ماند و پاک نمی‌شود. سرویس‌ورکر فایل‌های تغییرنکرده را از کش قبلی برمی‌دارد.

برای ساخت بستهٔ قابل انتشار موبایل/وب:

```bash
npm run build
npm run package:mobile
```

خروجی در `release/ghadam-mobile-pwa.zip` ساخته می‌شود. این ZIP شامل فایل‌های وب‌اپ و راهنمای فارسی نصب است و باید روی یک میزبان HTTPS منتشر شود؛ خودش فایل نصب اندروید نیست.

## نکته‌های مهم

- داده‌ها در `localStorage` همین مرورگر ذخیره می‌شوند؛ همگام‌سازی ابری یا حساب کاربری وجود ندارد. پاک‌کردن داده‌های مرورگر، پیشرفت را پاک می‌کند. برای جابه‌جایی دستگاه از پشتیبان استفاده کنید.
- پخش صدا به وجود صدای انگلیسی در مرورگر/سیستم‌عامل بستگی دارد. اگر در دسترس نباشد، متن و راهنمای فارسی تلفظ همچنان در دسترس است. راهنمای فارسی تقریبی است و جای تلفظ صوتی را کاملاً نمی‌گیرد.
- پس از نصب نسخهٔ آفلاین، درس‌ها و تمرین‌ها بدون اینترنت کار می‌کنند؛ برخی صداهای مرورگر ممکن است به اتصال اینترنت نیاز داشته باشند.
- محتوا برای شروع یادگیری است، نه سنجش رسمی سطح زبان. همهٔ درس‌ها از ابتدا باز هستند.

## ساختار

- `src/data/curriculum.ts`: محتوای درس‌ها
- `src/lib/learning.ts`: وضعیت یادگیری، تولید تمرین و زمان‌بندی مرور
- `src/hooks/`: ذخیره‌سازی و تلفظ
- `src/components/`: صفحه‌ها، تمرین، تنظیمات و اجزای رابط
- `src/styles*.css`: طراحی واکنش‌گرا و خوانایی
- `tests/app.spec.ts`: آزمون‌های یکپارچهٔ مرورگر
- `tests/production.mjs`: آزمون کش آفلاین و ادامهٔ تمرین در نسخهٔ ساخت‌شده
- `vite.config.ts`: ساخت و تولید سرویس‌ورکر آفلاین

ساخته‌شده با React، TypeScript، Vite، Lucide و قلم‌های محلی Vazirmatn و Manrope.
